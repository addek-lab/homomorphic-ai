My lab setup: testing encrypted inference myself

Reading about FHE only gets you so far. Every paper says "practical", and the word means something different each time. So my rule is simple: no claim about performance goes into my notes unless I measured it on my own hardware.

The tools

  • Concrete ML (Zama): the fastest way to go from a scikit-learn or PyTorch model to an FHE-compatible one. It quantizes the model and compiles it to a TFHE circuit.
  • OpenFHE and Microsoft SEAL: lower-level libraries where I can pick the scheme (BFV, BGV, CKKS) and set parameters by hand. This is where I learn what the knobs actually do.

A first experiment, in code

The smallest meaningful test is a plain classifier. In Concrete ML the flow looks like this:

from concrete.ml.sklearn import LogisticRegression

model = LogisticRegression(n_bits=8)
model.fit(X_train, y_train)
model.compile(X_train)                      # build the FHE circuit

y_clear = model.predict(X_test)             # plaintext baseline
y_fhe   = model.predict(X_test, fhe="execute")  # encrypted inference

The point is the comparison between the last two lines: do the predictions agree, and what does the second one cost?

What I measure

  1. Accuracy gap: plaintext vs. encrypted predictions, after quantization.
  2. Latency: time per inference, split into encryption, evaluation and decryption.
  3. Ciphertext expansion: size of the encrypted input compared with the raw input.
  4. Memory: peak RAM during evaluation, since it often limits model size before time does.
  5. Parameter sensitivity: how results change when I vary bit-width and security level.

How I keep it honest

  • Every run records hardware, library version and parameters next to the result.
  • I always report the plaintext baseline alongside the encrypted number.
  • I publish negative results too. A model that is too slow to be useful is a finding.
I'll publish measured numbers in this log once I have a reproducible benchmark. Until then, anything on this site about speed is a general statement from the literature, not my own result.
