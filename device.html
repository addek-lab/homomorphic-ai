CONCEPT · HARDWARE MOCKUP

The Cheap Yellow Device

A pocket-sized client for Homomorphic AI. Built on the ESP32 "Cheap Yellow Display", it holds your keys, encrypts data before it leaves your hands, and decrypts the answer. The cloud does the thinking, blind.

ESP32-2432S028R
microSD · USB-C · CH340 2.8" 320×240 touch

Tap the screen buttons. This is a simulation: values and ciphertext are illustrative, no real encryption runs here.

How you'd use it

Example: check a health reading against a cloud risk model without the cloud ever seeing the number.

    Division of labour

    ON THE DEVICE

    Keys & crypto I/O

    • Generate and store the secret key
    • Encrypt small inputs (sensor value, short vector)
    • Decrypt the returned result
    • Show status on the touchscreen

    OVER Wi-Fi

    Ciphertext only

    • Device uploads encrypted input + public/evaluation keys
    • Secret key never leaves the board
    • Result comes back encrypted

    IN THE CLOUD

    Blind inference

    • Runs the model on ciphertext
    • Heavy lifting: GPUs or servers
    • Learns nothing about input or output

    Reality check

    • Memory is the wall. FHE ciphertexts and keys are large, and ~520 KB RAM is tight. Parameters must stay small.
    • No evaluation on-device. Running a model on ciphertext is not realistic here; that's the cloud's job.
    • Feasibility unverified. Whether encryption/decryption with FHE-grade parameters runs acceptably on the ESP32 is something I still need to prototype. Embedded FHE is an active research area.
    • Fallback: the board can act as a secure key holder and display while a phone or PC does the heavy encryption.

    Build roadmap
