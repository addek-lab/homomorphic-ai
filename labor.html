Homomorphic Lab

Eine kleine Software für eigene Experimente mit verschlüsselter KI. Sie nutzt die Open-Source-Bibliothek OpenFHE und lässt ganz normale scikit-learn-Modelle auf verschlüsselten Daten rechnen. Der „Server“ sieht weder die Eingabe noch das Ergebnis.

homomorphic-lab.zip herunterladen Schnellstart

Python-Quellcode, MIT-Lizenz. Läuft in Docker oder unter Linux/WSL2 (siehe Voraussetzungen).

Vom Problem über die Idee bis zum ersten Experiment, mit Sprache und Untertiteln. Du brauchst keine Vorkenntnisse.

Textfassung des Videos

1 · Das Problem. Stell dir vor, du nutzt eine KI-App, die dein Gesundheitsrisiko schätzt. Du tippst deine Werte ein, und sie landen auf dem Server des Anbieters. Dort kann jeder sie lesen, der Zugriff hat.

2 · Die Idee. Mit homomorpher Verschlüsselung geht es anders. Dein Gerät verschlüsselt die Werte, bevor sie es verlassen. Der Server sieht nur Zufallszeichen, rechnet aber trotzdem damit. Das Ergebnis kommt verschlüsselt zurück, und nur du kannst es öffnen.

3 · Starten. Genau das kannst du mit dem Homomorphic Lab selbst ausprobieren. Lade die ZIP-Datei von der Webseite, entpacke sie und starte sie mit Docker. Zwei Befehle genügen.

4 · Experiment 3. Experiment 3 zeigt eine verschlüsselte Diagnose. Ein ganz normales KI-Modell bewertet Messwerte, die der Server nie im Klartext sieht. Das Ergebnis stimmt mit der normalen Berechnung überein.

5 · Dein Modell. Du kannst auch dein eigenes Modell nutzen. Speichere es als joblib-Datei, lege deine Daten als CSV daneben und starte Experiment 5.

6 · Und ChatGPT & Co.? Ehrlich gesagt: Solche Chatbots können verschlüsselte Eingaben heute noch nicht verarbeiten. Dafür sind sie zu groß. Möglich sind kleine Modelle wie im Lab. Ein KI-Assistent kann dir aber beim Lernen helfen: Er erklärt dir die Ausgaben oder passt den Code an. Gib dort nur nie echte, private Daten ein.

7 · Ausprobieren. Alles ist kostenlos auf der Webseite, auf der Seite „Labor“. Es ist Lehrsoftware und nicht für echte, sensible Daten gedacht.

Die Sprache im Video ist eine Computerstimme. Die Terminal-Ausgaben stammen aus echten Testläufen (teils gekürzt dargestellt). Die Docker-Befehle zeigen den vorgesehenen Ablauf, den ich selbst noch nicht ausführen konnte (siehe Teststand unten).

Schnellstart

Mit Docker (empfohlen)

Funktioniert unter Windows, macOS und Linux. ZIP entpacken, im Ordner ausführen:

docker build -t homomorphic-lab .
docker run --rm -it homomorphic-lab
docker run --rm -it homomorphic-lab python run.py 3

Auf ARM-Rechnern (z. B. Apple Silicon) läuft der Container per Emulation, das ist langsamer.

Ohne Docker (Linux / WSL2)

Linux x86_64 mit Python 3.12:

python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python run.py

Voraussetzungen

  • Das pip-Paket openfhe gibt es nur für Linux auf x86_64 mit Python 3.12. Unter Windows und macOS also Docker oder WSL2 nutzen.
  • Docker Desktop oder eine Linux-Umgebung, etwa 1 GB freier Speicherplatz.
  • Keine Internetverbindung beim Rechnen nötig; nur beim Installieren der Pakete.
  • Teststand: Alle fünf Experimente liefen gegen OpenFHE 1.6.1 unter Linux (ARM64, aus dem Quellcode gebaut). Das mitgelieferte Docker-Image (x86_64) konnte ich selbst noch nicht bauen und starten, weil mir dafür das Docker-Umfeld fehlte. Rückmeldungen sind willkommen.

Wie es funktioniert

CLIENT

Verschlüsselt den Merkmalsvektor mit dem öffentlichen Schlüssel und behält den geheimen Schlüssel.

SERVER

Rechnet Gewichte mal Merkmale plus Bias direkt auf dem Chiffretext. Er kennt nur das Modell, nicht die Daten.

CLIENT

Entschlüsselt das Ergebnis und trifft die Entscheidung, bei Bedarf mit angewendeter Sigmoid-Funktion.

Mehr Hintergrund zu Rauschen, Bootstrapping und Kosten in der Wissensbasis.

UND KI-ASSISTENTEN?

ChatGPT & Co. und das Lab

Ehrlich vorweg: Das Lab verbindet sich nicht mit Chatbots, und Chatbots können heute keine verschlüsselten Eingaben verarbeiten. Sprachmodelle sind dafür viel zu groß und zu langsam. Das ist noch Forschung. Was geht, ist Folgendes:

GEHT NOCH NICHT

Verschlüsselter Chat

Ein Chatbot, der auf deinem verschlüsselten Prompt rechnet, ohne ihn zu lesen. Das ist eine offene Forschungsfrage.

GEHT

Kleine Modelle

Risikowerte, Klassifikation und ähnliche Aufgaben mit kleinen Modellen, so wie in den Experimenten. Das Lab zeigt genau das.

GEHT

KI als Lernhilfe

Ein KI-Assistent erklärt dir Ausgaben, schreibt Code für dein eigenes Modell und beantwortet Fragen zum Lab.

Fertige Fragen für deinen KI-Assistenten

Kopiere sie in den Assistenten deiner Wahl. Die Beispiel-Ausgaben des Labs enthalten keine privaten Daten (öffentlicher Datensatz).

Wichtig: Füge in Chat-Assistenten nie echte, private Daten ein (Gesundheits-, Finanz- oder Ausweisdaten). Das Lab schützt nur das, was du im Lab verschlüsselst, nicht das, was du in einen Chat tippst.

Grenzen

  • Lehrcode: Schlüsselverwaltung, Schlüsselrotation und Netzwerkübertragung sind nicht umgesetzt.
  • Nur Inferenz: Kein Training auf verschlüsselten Daten.
  • Lineare Modelle: Neuronale Netze mit ReLU sind mit CKKS nicht direkt möglich und deshalb nicht enthalten.
  • Näherung: CKKS rechnet ungefähr; Ergebnisse weichen minimal vom Klartext ab. Die Experimente zeigen den Abstand.
  • Eigene Modelle: joblib-Dateien können beim Laden Code ausführen. Nur Dateien laden, denen man vertraut.
