Homomorphic Lab

Eine kleine Software für eigene Experimente mit verschlüsselter KI. Sie nutzt die Open-Source-Bibliothek OpenFHE und lässt ganz normale scikit-learn-Modelle auf verschlüsselten Daten rechnen. Der „Server“ sieht weder die Eingabe noch das Ergebnis.

homomorphic-lab.zip herunterladen Schnellstart

Python-Quellcode, MIT-Lizenz. Läuft in Docker oder unter Linux/WSL2 (siehe Voraussetzungen).

Fünf Experimente

EXPERIMENT 1

Hallo, verschlüsselte Welt

Zahlen verschlüsseln, addieren, multiplizieren und verschieben, ohne je zu entschlüsseln.

EXPERIMENT 2

Rauschen und Rechentiefe

Sieh, wie das Rauschen wächst und warum nur begrenzt viele Multiplikationen hintereinander gehen.

EXPERIMENT 3

Verschlüsselte Diagnose

Ein normales Modell (logistische Regression) bewertet Brustkrebs-Messwerte, die der Server nie im Klartext sieht.

EXPERIMENT 4

Parameter und Kosten

Tiefe und Genauigkeit gegen Ringgröße, Chiffretext-Größe und Zeit abwägen.

EXPERIMENT 5

Dein eigenes Modell

Eigenes scikit-learn-Modell (joblib) und CSV-Daten verschlüsselt auswerten.

WICHTIG

Lehrsoftware

Zum Lernen und Ausprobieren, nicht für echte sensible Daten im Produktivbetrieb.

Schnellstart

Mit Docker (empfohlen)

Funktioniert unter Windows, macOS und Linux. ZIP entpacken, im Ordner ausführen:

docker build -t homomorphic-lab .
docker run --rm -it homomorphic-lab
docker run --rm -it homomorphic-lab python run.py 3

Auf ARM-Rechnern (z. B. Apple Silicon) läuft der Container per Emulation, das ist langsamer.

Ohne Docker (Linux / WSL2)

Linux x86_64 mit Python 3.12:

python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python run.py

Voraussetzungen

  • Das pip-Paket openfhe gibt es nur für Linux auf x86_64 mit Python 3.12. Unter Windows und macOS also Docker oder WSL2 nutzen.
  • Docker Desktop oder eine Linux-Umgebung, etwa 1 GB freier Speicherplatz.
  • Keine Internetverbindung beim Rechnen nötig; nur beim Installieren der Pakete.
  • Teststand: Alle fünf Experimente liefen gegen OpenFHE 1.6.1 unter Linux (ARM64, aus dem Quellcode gebaut). Das mitgelieferte Docker-Image (x86_64) konnte ich selbst noch nicht bauen und starten, weil mir dafür das Docker-Umfeld fehlte. Rückmeldungen sind willkommen.

Wie es funktioniert

CLIENT

Verschlüsselt den Merkmalsvektor mit dem öffentlichen Schlüssel und behält den geheimen Schlüssel.

SERVER

Rechnet Gewichte mal Merkmale plus Bias direkt auf dem Chiffretext. Er kennt nur das Modell, nicht die Daten.

CLIENT

Entschlüsselt das Ergebnis und trifft die Entscheidung, bei Bedarf mit angewendeter Sigmoid-Funktion.

Mehr Hintergrund zu Rauschen, Bootstrapping und Kosten in der Wissensbasis.

Grenzen

  • Lehrcode: Schlüsselverwaltung, Schlüsselrotation und Netzwerkübertragung sind nicht umgesetzt.
  • Nur Inferenz: Kein Training auf verschlüsselten Daten.
  • Lineare Modelle: Neuronale Netze mit ReLU sind mit CKKS nicht direkt möglich und deshalb nicht enthalten.
  • Näherung: CKKS rechnet ungefähr; Ergebnisse weichen minimal vom Klartext ab. Die Experimente zeigen den Abstand.
  • Eigene Modelle: joblib-Dateien können beim Laden Code ausführen. Nur Dateien laden, denen man vertraut.
